# 零一扬科技设计系统

版本：1.0  
适用范围：01yang.space 品牌与数字产品  
设计方向：Monochrome Minimalism · Functional Glass · AI Native

## 1. 品牌核心

- 公司主体：福州零一扬网络科技有限公司
- 品牌简称：零一扬科技 / 01YANG
- 首页标题：从 0 到 1，让智能真正落地
- 品牌 Slogan：让每一个想法，拥有智能生长的力量
- 业务解释：以 AI 为引擎，连接模型、软件与业务，把想法转化为真正可用的产品
- 品牌人格：清晰、克制、可靠、好奇、面向未来

“零一”表达从无到有和数字技术；“扬”表达让价值被看见。视觉不使用泛滥的蓝紫 AI 渐变，而通过黑白、高对比、光束和空间感建立独特识别。

## 2. 设计原则

1. **内容先于装饰**：首屏必须首先说明公司做什么，视觉只用于强化信息层级。
2. **单一主动作**：每个屏幕至多有一个明确主 CTA，次要动作降低视觉权重。
3. **玻璃有功能**：毛玻璃用于固定导航和 CTA 表面，表达层级，不在所有卡片上滥用。
4. **动态有原因**：导航变化对应滚动状态，内容入场对应进入视口，按钮反馈对应用户操作。
5. **黑白不等于低对比**：正文、次要文字、边框分别满足可读性和层级需求。
6. **真实胜过夸张**：不使用无法验证的行业排名、客户量、成功率或绝对化承诺。

## 4. 字体与排版

- 西文与数字：Geist Sans / Geist Mono
- 中文：PingFang SC → Microsoft YaHei → 系统无衬线
- 标题字重：590–650；正文：400–520；标签：560–620
- 大标题字距：-0.05em 至 -0.075em
- 正文字距：保持系统默认
- 正文行高：1.7–1.85
- 正文最小字号：移动端 15px，表单输入未来不得小于 16px
- 标签最小字号：10px，仅用于非关键英文眉题且保持足够对比

### 字级

| 角色 | 建议尺寸 |
|---|---|
| Hero Display | clamp(54px, 8.4vw, 116px) |
| Section Display | clamp(42px, 6.2vw, 82px) |
| Card Title | clamp(25px, 2.7vw, 36px) |
| Lead | 19–27px |
| Body Large | 16–19px |
| Body | 15–16px |
| Label | 10–12px |

中文标题每行优先控制在 8–16 个汉字；正文桌面单行不超过约 36 个汉字。

## 5. 布局与间距

- 基础单位：4px；主要节奏使用 8px 倍数
- 桌面容器：最大 1200px，左右至少 24px
- 手机容器：左右 16px
- Section 垂直间距：112–184px 自适应
- 卡片间距：16px
- 栅格：桌面 12 列，平板 2 列，手机 1 列
- 固定导航顶距：16px + safe-area
- 锚点滚动预留：88px

断点基准：

- Small：375px
- Medium：768px
- Large：1024px
- Wide：1440px

任何宽度下不得出现主体横向滚动。固定元素不得遮挡锚点标题或可操作内容。

## 6. 组件规范

### Pill Navigation

- 高度：52px 外框；每个触控项 44px
- 默认：纯黑外框 + 白色胶囊
- 滚动后：深色 62% 透明度、22px blur、白色 16% 边框
- 当前项：小圆点标识，不仅依赖颜色
- Hover：深色填充从下进入，标签纵向切换
- 手机：Logo 与菜单按钮分列，菜单使用同层级深色玻璃面板

### Buttons

- 形状：999px 圆角胶囊
- 最小高度：48px
- 水平内边距：22–28px
- 主按钮：白底黑字
- 次按钮：透明白 9%、1px 半透明边框、16px blur
- Hover：向上 2px；Pressed：缩放至 0.97
- 所有状态不得改变布局边界

### Service Cards

- 圆角：桌面 32px，手机 26px
- 内边距：28–42px
- 默认：白色 76% 表面、低对比边框、极轻阴影
- 重点卡：黑色表面、白字、单一抽象圆形细节
- 图标：Lucide 线性图标，统一 1.6px stroke
- 卡片本身若没有跳转，不添加虚假指针或按钮样式

### Contact CTA

- 使用深色玻璃长胶囊
- 明确显示动作与真实目标邮箱
- 末端使用 64px 白色圆形箭头
- 上线前必须确认邮箱可收件

## 7. 动效系统

### 时长

| 令牌 | 时长 | 用途 |
|---|---:|---|
| motion-fast | 180–220ms | Press、退出、焦点邻近反馈 |
| motion-base | 240–320ms | Hover、菜单、导航状态 |
| motion-enter | 700–820ms | 区块入场 |
| motion-line | 1000ms | 分隔线展开 |

### 缓动

- 主进入：power3.out
- 微交互：power2.out
- CSS：cubic-bezier(0.16, 1, 0.3, 1)

### 规则

- 只动画 transform 与 opacity
- 内容入场：Y 方向 28–42px + Fade
- 同组首屏元素错峰 90ms
- 列表如需错峰保持 30–50ms，避免等待过长
- 动画必须可中断，不阻止用户滚动或点击
- 不使用大幅视差、鼠标追随或滚动劫持
- prefers-reduced-motion: reduce 时关闭连续背景、入场与平滑滚动

## 8. 玻璃与阴影

玻璃表面必须同时具备：

- 足以阅读的实际底色
- 1px 半透明边框
- 16–24px 背景模糊
- 极弱内高光
- 不超过两层阴影

禁止在浅色正文卡片大面积使用高透明玻璃；这会降低层级和文字对比。

## 9. 图标与图像

- 结构图标统一使用 Lucide，默认 stroke 1.6–1.8px
- 不使用 Emoji 作为导航、服务或状态图标
- 品牌主视觉优先使用 CSS、WebGL 光束和排版，不使用无意义图库人物
- 社交分享图为独立横图，不作为正文关键内容
- 未来使用照片时优先 AVIF/WebP，声明尺寸并延迟加载非首屏资源

## 10. 无障碍

- 正常正文对比度至少 4.5:1；大文字至少 3:1
- 可操作区域最小 44×44px，目标间距至少 8px
- 保留 :focus-visible，不得移除 outline
- 提供“跳到主要内容”链接
- 标题从 H1 到 H2/H3 顺序递进
- 装饰性 Canvas 与图标对屏幕阅读器隐藏
- 当前导航同时使用 aria-current
- 移动菜单暴露展开状态，关闭时内部链接退出 Tab 顺序
- 不以颜色作为唯一状态指示
- 页面允许浏览器缩放，不禁止 pinch zoom

## 11. 性能

- 首屏文案与导航不等待 WebGL
- Beams 客户端异步加载并限制 DPR 上限
- 避免全局第三方脚本
- 高频滚动状态通过 requestAnimationFrame 合并
- 下方内容不依赖远程图片
- 避免动画触发布局和 CLS
- 生产构建必须通过后才能发布

## 12. 内容与合规

- 正式用语：AI 模型 API 聚合与接入服务
- 内部口语“AI 中转站”不作为首页正式服务名
- 不使用“领先、最稳定、绝对安全、零故障、无限”等无依据承诺
- 不暗示第三方模型为公司自研
- 客户 Logo、评价、案例与数据必须有授权并可验证
- 网络技术服务需说明具体范围，不暗示需要额外许可的电信业务
- AI 教育不承诺就业、收入、证书效力或必然学习结果
- 页脚以公司法定主体为准，后续补充真实备案和法律文件

## 13. 禁止模式

- 彩色霓虹 AI 渐变
- 每个区块都使用毛玻璃
- Emoji 图标
- 装饰性无限动画
- 低对比灰字叠加透明背景
- 小于 44px 的点击区域
- 虚构客户、指标、评价或认证
- 自动播放声音或滚动劫持
- 为未来可能性增加当前不需要的抽象与依赖
