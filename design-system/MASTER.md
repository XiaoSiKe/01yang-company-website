# 零一扬科技设计系统

版本：1.4
适用范围：01yang.space 品牌与数字产品  
设计方向：Monochrome Minimalism · Functional Glass · AI Native

## 1. 品牌核心

- 公司主体：福州零一扬网络科技有限公司
- 品牌简称：零一扬科技 / 01YANG
- 首页标题：福州零一扬网络科技有限公司
- 品牌 Slogan：从零到一，让人工智能真正落地！
- 品牌人格：清晰、克制、可靠、好奇、面向未来

“零一”表达从无到有和数字技术；“扬”表达让价值被看见。视觉不使用泛滥的蓝紫 AI 渐变，而通过黑白、高对比、光束和空间感建立独特识别。

## 2. 设计原则

1. **内容先于装饰**：首屏必须首先说明公司做什么，视觉只用于强化信息层级。
2. **单一主动作**：每个屏幕至多有一个明确主 CTA，次要动作降低视觉权重。
3. **玻璃有功能**：毛玻璃用于固定导航和 CTA 表面，表达层级，不在所有卡片上滥用。
4. **动态有原因**：导航变化对应滚动状态，内容入场对应进入视口，按钮反馈对应用户操作。
5. **黑白不等于低对比**：正文、次要文字、边框分别满足可读性和层级需求。
6. **真实胜过夸张**：不使用无法验证的行业排名、客户量、成功率或绝对化承诺。

## 4. 字体与排版

- 西文与数字：Geist Sans / Geist Mono
- 中文：PingFang SC → Microsoft YaHei → 系统无衬线
- 标题字重：600–650；正文：400–520；标签：600
- 大标题字距：-0.05em 至 -0.075em
- 正文字距：保持系统默认
- 正文行高：1.7–1.85
- 正文最小字号：16px，表单输入未来不得小于 16px
- 标签最小字号：10px，仅用于非关键英文眉题且保持足够对比

### 字级

| 角色 | 建议尺寸 |
|---|---|
| Hero Display | clamp(54px, 8.4vw, 116px) |
| Section Display | clamp(44px, 4.8vw, 68px)；手机 clamp(36px, 10vw, 46px) |
| Card Title | clamp(24px, 2vw, 30px)；手机 24px |
| Process Title | 24–26px；手机 23px |
| Lead | 16–17px |
| Body | 16px |
| Facts | 14px |
| Label | 10–12px |

中文标题每行优先控制在 8–16 个汉字；正文桌面单行不超过约 36 个汉字。

## 5. 布局与间距

- 基础单位：4px；主要节奏使用 8px 倍数
- 桌面容器：最大 1200px，左右至少 24px
- 手机容器：左右 16px
- Section 垂直间距：104–152px 自适应；手机统一 88px
- 卡片间距：16px
- 栅格：桌面 12 列，平板 2 列，手机 1 列
- 固定导航顶距：safe-area；滚动后下移 12px
- 模块标题容器：最大 900px，统一从内容容器左侧起排
- 锚点滚动预留：88px；锚点必须挂在真实内容容器，而不是带顶部内边距的 Section 外框

断点基准：

- Small：375px
- Medium：768px
- Large：1024px
- Wide：1440px

任何宽度下不得出现主体横向滚动。固定元素不得遮挡锚点标题或可操作内容。

## 6. 组件规范

### Pill Navigation

- 默认：64px 高、接近全宽的透明导航；品牌 Logo 居左，文字导航居右
- 导航文字：15px、白色 72%；当前项与 Hover 提升为纯白
- 滚动后：收拢为居中 48px 高胶囊，最大宽度 540px、29px 圆角；容纳“关于零一 / 服务与合作”等完整标签
- 滚动玻璃：黑色 26% 覆盖、40px blur + 180% 饱和度、白色 18% 边框、内高光与柔和阴影
- 形态切换：使用 700ms `--ease-out` 同步过渡宽度、高度、位移与玻璃表面
- 手机：Logo 与菜单按钮分列，菜单使用同层级深色玻璃面板

### Buttons

- 组件：SpecularButton；页面 CTA 使用 `lg` 尺寸与 18px 圆角，服务轮换等紧凑控制允许使用 `sm`
- 表面：白色 tint、0 透明度、0 blur；文字 `#FFFFFF`
- 边缘：高光 `#FFFFFF`、基础描边 `#525252`、1px 厚度
- 高光：intensity 1、shineSize 10、shineFade 40、speed 0.35
- 交互：250px 范围内跟随鼠标；不自动播放；Pressed 缩放至 0.97
- 所有状态不得改变布局边界

### Service Cards

- 圆角：桌面 32px，手机 26px
- 内边距：28–38px；手机 24px
- 卡面：由 CardSwap 统一提供黑色 88% 表面、白色 15% 边框、白字、内高光与阴影
- 重点卡：继承同一卡面，仅通过编号、图标与悬浮边框强度区分层级
- 展示方式：CardSwap 卡片栈；水平距离上限 60px、垂直距离上限 70px、每 5000ms 换位
- 五项服务全部进入同一卡片栈；小屏根据可用空间收敛距离，不缩小正文
- 提供清晰的“暂停轮换 / 继续轮换”控制；悬浮本身不暂停
- 减少动态效果时关闭自动换位，并将全部服务展开为静态网格
- 图标：Lucide 线性图标，统一 1.6px stroke
- 卡片本身若没有跳转，不添加虚假指针或按钮样式

### Module Headers

- Services、Approach、About、Contact 共用 `Kicker → H2 → Intro` 的纵向结构
- 所有标题、眉题和说明均左对齐，并与页面内容容器左边缘一致
- Kicker 与标题组间距 24px；H2 与 Intro 间距 24px
- 标题组最大宽度 900px；Intro 最大宽度 620px
- 标题组到主体内容的距离为 64–88px；手机为 48px
- About 可省略 Intro，但不得把主标题放入右侧内容列

### Logo Loop

- 只用于 Contact 模块底部、页脚上方的单条横向核心技术栈，不叠加竖向循环
- 图标高度 48px、间距 40px、向左速度 80px/s
- 悬浮或键盘聚焦时暂停，图标可轻微放大；边缘使用 `#050505` 淡出
- 减少动态效果时停止循环并保留一组静态技术图标

### Accordion Gallery

- 用于 Services 模块下方的项目实践预览；当前使用占位图片，后续替换为真实项目图与链接
- 桌面为五列横向折叠，当前项约占 52%；手机切换为纵向折叠，避免横向手势冲突
- 桌面支持悬浮，键盘聚焦与触摸点击同样可以展开，不把 Hover 作为唯一操作方式
- 图片统一使用黑白处理与深色渐隐，面板间距 8px；减少动态效果时取消展开过渡

### Contact CTA

- 使用同参数 SpecularButton 长按钮
- 明确显示动作与真实目标邮箱
- 末端使用 64px 深色圆形箭头，配白色细边与图标
- 微信二维码使用深色玻璃外框，但二维码本体保持标准黑码白底与完整静区
- 不对二维码应用反相、透明度、模糊、混合模式或连续动画
- 上线前必须确认邮箱可收件，并用真实微信复测二维码

## 7. 动效系统

### 时长

| 令牌 | 时长 | 用途 |
|---|---:|---|
| motion-fast | 180–220ms | Press、退出、焦点邻近反馈 |
| motion-base | 240–320ms | Hover、菜单、导航状态 |
| motion-enter | 700–820ms | 区块入场 |
| motion-line | 1000ms | 分隔线展开 |

### 缓动

- 主进入：power3.out
- 微交互：power2.out
- CSS：cubic-bezier(0.16, 1, 0.3, 1)

### 规则

- 滚动入场只动画 transform 与 opacity
- 导航形态、AccordionGallery 展开与 ShinyText 扫光按各自 Module 规范执行，不纳入滚动入场限制
- 内容入场：Y 方向 28–42px + Fade
- 首屏如存在同组多元素，错峰 90ms；当前 Hero CTA 作为单一容器入场
- 列表如需错峰保持 30–50ms，避免等待过长
- 动画必须可中断，不阻止用户滚动或点击
- 不使用大幅视差、鼠标追随或滚动劫持
- prefers-reduced-motion: reduce 时关闭连续背景、入场与平滑滚动

## 8. 玻璃与阴影

玻璃表面必须同时具备：

- 足以阅读的实际底色
- 1px 半透明边框
- 16–24px 背景模糊
- 极弱内高光
- 不超过两层阴影

禁止在浅色正文卡片大面积使用高透明玻璃；这会降低层级和文字对比。

## 9. 图标与图像

- 结构图标统一使用 Lucide，默认 stroke 1.6–1.8px
- 不使用 Emoji 作为导航、服务或状态图标
- 品牌主视觉优先使用 CSS、WebGL 光束和排版，不使用无意义图库人物
- 社交分享图为独立横图，不作为正文关键内容
- 未来使用照片时优先 AVIF/WebP，声明尺寸并延迟加载非首屏资源

## 10. 无障碍

- 正常正文对比度至少 4.5:1；大文字至少 3:1
- 可操作区域最小 44×44px，目标间距至少 8px
- 保留 :focus-visible，不得移除 outline
- 提供“跳到主要内容”链接
- 标题从 H1 到 H2/H3 顺序递进
- 装饰性 Canvas 与图标对屏幕阅读器隐藏
- 当前导航同时使用 aria-current
- 移动菜单暴露展开状态，关闭时内部链接退出 Tab 顺序
- 不以颜色作为唯一状态指示
- 页面允许浏览器缩放，不禁止 pinch zoom

## 11. 性能

- 首屏文案与导航不等待 WebGL
- Beams 客户端异步加载并限制 DPR 上限
- 避免全局第三方脚本
- 高频滚动状态通过 requestAnimationFrame 合并
- 页面不依赖远程占位图片；AccordionGallery 当前图片已同图本地化，真实案例上线前替换为项目资源
- 避免动画触发布局和 CLS
- 生产构建必须通过后才能发布

## 12. 内容与合规

- 正式用语：AI 模型 API 聚合与接入服务
- 内部口语“AI 中转站”不作为首页正式服务名
- 不使用“领先、最稳定、绝对安全、零故障、无限”等无依据承诺
- 不暗示第三方模型为公司自研
- 客户 Logo、评价、案例与数据必须有授权并可验证
- 网络技术服务需说明具体范围，不暗示需要额外许可的电信业务
- AI 教育不承诺就业、收入、证书效力或必然学习结果
- 页脚以公司法定主体为准，后续补充真实备案和法律文件

## 13. 禁止模式

- 彩色霓虹 AI 渐变
- 每个区块都使用毛玻璃
- Emoji 图标
- 装饰性无限动画
- 低对比灰字叠加透明背景
- 小于 44px 的点击区域
- 虚构客户、指标、评价或认证
- 自动播放声音或滚动劫持
- 为未来可能性增加当前不需要的抽象与依赖
