# 首页规范覆盖

本文件只记录首页相对于 MASTER.md 的具体实现决策；未提及内容全部继承主规范。

## 信息顺序

1. Hero：公司中英文标题、Slogan、成立日期与两个 CTA
2. About：公司主体、创始人、成立时间与四项核心服务能力
3. Services：项目实践标题与三项可点击折叠画廊
4. Contact：合作邀请、QQ 二维码、核心技术栈与法定主体页脚

## 视觉节奏

- 整页使用近白、中灰、银灰三色的动态 ColorBends 固定背景，形成黑底银白光带并在滚动时无缝延续。
- About、Services 与 Contact 保持透明，不切换浅色表面。
- 全页使用黑色表面与白色字体体系，仅通过白色透明度建立信息层级。
- About 使用 BorderGlow 深色内容面板，展示公司介绍、单行主体信息与四张服务能力卡；主体信息区不使用上下分隔线。
- Services 只展示“第二十五小时”“零一 API”“零一 AI 日新社”三项 AccordionGallery 项目卡，不显示序号。
- 项目画廊使用用户提供的三张对应网站首页图作为封面，通过 `object-fit: cover` 填满卡片；默认黑白，鼠标悬停或键盘聚焦时显示彩色。
- 内容默认可见；滚动入场只在元素进入视口时执行，不以预先隐藏内容作为动效前置条件。
- Contact 底部、页脚上方使用一条横向 LogoLoop 展示 React、Next.js、TypeScript 与 Tailwind CSS；不使用竖向循环。

## 模块标题与内容排版

- About、Services、Contact 的 H2 全部从页面内容容器左侧起排，不再显示编号眉题。
- 非首屏 H2 直接复用日新社官网 `home-flow-title`：`24–34px / 800 / 1.2`，白—蓝—紫渐变以 3 秒线性循环流动；手机固定 24px。
- 模块说明统一为 `16–17px / 1.75`，正文统一为 16px；卡片标题控制在 24–30px。
- About 标题为“关于零一”，Services 标题为“产品与服务”；About 内部主标题与“我们在做什么？”使用 18–22px，成立与创始人信息使用 16px 正文字号。
- Contact 标题置于模块顶部，不使用纵向居中；页脚三行文字居中排列。
- 模块上下留白收紧为 64–88px，手机为 56px。

## 导航锚点

- 服务、关于、联系使用原生页内锚点和平滑滚动，不增加滚动劫持逻辑。
- 导航顺序为：首页 → 关于零一 → 产品与服务 → 联系与合作。
- `services`、`about`、`contact` 等 ID 挂在紧邻标题的内容容器上，并预留 88px 固定导航空间。
- 移动菜单点击后只关闭菜单；仅通过 Escape 关闭时把焦点恢复到菜单按钮。

## 首屏文案

- 标题：福州零一扬网络科技有限公司
- Slogan：从零到一，让人工智能真正落地！
- 公司英文胶囊：`FUZHOU 01YANG NETWORK TECHNOLOGY CO., LTD.`，位于标题上方，带 `01` 圆形标识。
- 成立日期胶囊：`成立于 · 2026.1.26`，位于 Slogan 与 CTA 之间；点击跳转至 About。
- 首屏不增加业务摘要；英文与日期胶囊仅承载公司身份元信息，服务范围在下一区块展开。
- 公司标题始终单行显示，并随视口宽度缩放；字号在上一版基础上放大 5%。
- Slogan 字号在上一版基础上放大 10%；首屏底部不展示能力标签条。

## 首屏动效

- ColorBends 使用 90° 旋转、0.2 速度、1 倍缩放、1 倍频率和 0.5 视差；减少动态偏好时停止连续刷新。
- 标题与 Slogan 在挂载时分别执行 StrokeDepthText 描边、填充与 DepthText 接续；CTA 随后由 GSAP 入场。
- CTA 入场时长 820ms，延迟 280ms；标题逐字节奏由 StrokeDepthText Module 自身参数控制。

## 联系模块动效

- 技术栈 LogoLoop 位于联系内容底部、页脚上方，使用 `80px/s` 向左循环、48px 图标和 40px 间距；减少动态效果时静态展示。

## 转化

- 主 CTA：产品与服务
- 次 CTA：联系与合作
- 联系区主标题为“联系与合作”，下方使用两段业务邀请与“下一个从零到一，从这里开始！”收束；收束语字号小于主标题。
- 在“搭建网络基础设施，”后强制换行；QQ 二维码排在收束语下方，最大宽度收紧为 270px，保持黑底白码，不显示内层边框或额外留黑。
- 页脚展示可跳转的 ICP 备案与公安备案链接；底部留白控制在 20–28px。
- 上线前使用真实 QQ 复测二维码。
