# 首页规范覆盖

本文件只记录首页相对于 MASTER.md 的具体实现决策；未提及内容全部继承主规范。

## 信息顺序

1. Hero：公司标题、Slogan、两个 CTA
2. Services：五项核心服务与项目实践预览
3. Approach：定义、构建、成长
4. About：公司主体、创始人与品牌含义
5. Contact：合作邀请、邮箱、微信二维码、核心技术栈与法定主体页脚

## 视觉节奏

- 整页使用与 Hero 相同的动态白色 Beams 固定背景，滚动时无缝延续。
- Services、Approach、About 与 Contact 保持透明，不再切换浅色表面。
- 全页使用黑色表面与白色字体体系，仅通过白色透明度建立信息层级。
- 服务卡使用近不透明黑色底，避免光束穿透正文影响阅读。
- 服务区左侧保留标题和说明，右侧使用 CardSwap 展示五项服务；小屏改为上下布局。
- CardSwap 使用 `60px / 70px / 5000ms` 参数，悬浮时继续播放，并提供暂停/继续按钮；减少动态效果时展开全部服务。
- 服务卡片之后使用五项 AccordionGallery 作为未来项目入口；桌面横向展开，手机纵向展开。
- Contact 底部、页脚上方使用一条横向 LogoLoop 展示 React、Next.js、TypeScript 与 Tailwind CSS；不使用竖向循环。

## 模块标题与内容排版

- Services、Approach、About、Contact 的眉题和 H2 全部从页面内容容器左侧起排。
- 标题统一使用 `44–68px / 600 / 1.08`，手机收敛到 `36–46px`，避免各模块尺度跳变。
- 模块说明统一为 `16–17px / 1.75`，正文统一为 16px；卡片标题控制在 24–30px。
- About 主标题置于模块左上方；`ZERO ONE YANG` 降为 56–88px 的品牌签名，不再压过主标题。
- Contact 标题置于模块顶部，不使用纵向居中；页脚继续停靠右下方。
- 模块上下留白为 104–152px，手机为 88px；标题组到内容区保持 64–88px，手机为 48px。

## 导航锚点

- 服务、关于、联系使用原生页内锚点和平滑滚动，不增加滚动劫持逻辑。
- 导航顺序为：首页 → 关于零一 → 服务与合作 → 联系。
- `services`、`about`、`contact` 等 ID 挂在紧邻标题的内容容器上，并预留 88px 固定导航空间。
- 移动菜单点击后只关闭菜单；仅通过 Escape 关闭时把焦点恢复到菜单按钮。

## 首屏文案

- 标题：福州零一扬网络科技有限公司
- Slogan：从零到一，让人工智能真正落地！
- 首屏不增加眉题或业务摘要，服务范围在下一区块展开。
- 公司标题始终单行显示，并随视口宽度缩放；字号在上一版基础上放大 5%。
- Slogan 字号在上一版基础上放大 10%；首屏底部不展示能力标签条。

## 首屏动效

- 光束使用 16 条、33° 旋转与 5.2 速度；减少动态偏好时停止连续刷新。
- 标题与 Slogan 在挂载时分别执行 StrokeDepthText 描边、填充与 DepthText 接续；CTA 随后由 GSAP 入场。
- CTA 入场时长 820ms，延迟 280ms；标题逐字节奏由 StrokeDepthText Module 自身参数控制。

## 联系模块动效

- 技术栈 LogoLoop 位于联系内容底部、页脚上方，使用 `80px/s` 向左循环、48px 图标和 40px 间距；减少动态效果时静态展示。
