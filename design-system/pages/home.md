# 首页规范覆盖

本文件只记录首页相对于 MASTER.md 的具体实现决策；未提及内容全部继承主规范。

## 信息顺序

1. Hero：公司定位、标题、Slogan、业务摘要、两个 CTA
2. Services：五项核心服务
3. Approach：定义、构建、成长
4. About：公司主体、创始人与品牌含义
5. Contact：合作邀请、邮箱与法定主体页脚

## 视觉节奏

- Hero 为全黑沉浸首屏，使用动态白色光束。
- Services 与 About 使用暖白 paper 表面，提供阅读停顿。
- Approach 与 Contact 回到纯黑表面，形成黑—白—黑—白—黑节奏。
- 服务区使用 7/5 + 4/4/4 Bento 栅格；移动端全部单列。

## 首屏文案

- 标题：从 0 到 1，让智能真正落地。
- Slogan：让每一个想法，拥有智能生长的力量。
- 摘要必须明确出现 AI、模型、软件与企业服务，不让诗意表达取代业务解释。

## 首屏动效

- 光束速度沿用需求值 5.2，但减少动态偏好时停止连续刷新。
- 标题组进入顺序：眉题 → 标题 → Slogan → 摘要 → CTA → 能力标签。
- 每项错峰 90ms，单项 820ms 内完成。

## 转化

- 主 CTA：探索我们的服务
- 次 CTA：开始合作
- 底部 CTA：联系合作，并直接显示 hello@01yang.space
- 上线前确认邮箱与域名邮件配置；未确认不得把邮件入口视为已验收。
